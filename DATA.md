# Данные

Файлы в репозиторий не включены: размер и лицензии. Скачай и положи так:

```
data/raw/
├── lexical_complexity/            # из lexical_complexity.zip
│   ├── word_complexity_ru_train.tsv
│   ├── word_complexity_ru_test.tsv
│   └── word_complexity_ru.tsv
└── auxiliary/
    └── rus_freq_dictionary_1992-2019.csv   # из data.zip (папка data/auxiliary)
```

| Файл | Источник | Лицензия |
|---|---|---|
| `lexical_complexity.zip` — 3364 слова в контексте (синодальная Библия), оценка сложности 0–0,8; разбиение по словам, общих слов в train и test нет | [Zenodo 7419194](https://zenodo.org/records/7419194), Иванов, Абрамов, Соловьёв | CC BY 4.0 |
| `data.zip` — мультидоменная разметка (документы ООН, биомедицина, шкала 1–5, по 10 разметчиков) и частотный словарь | [Zenodo 10251599](https://zenodo.org/records/10251599), Абрамов и др. (PACLIC 2023) | CC BY 4.0 |

Частотный словарь `rus_freq_dictionary_1992-2019.csv` лежит внутри `data.zip`, отдельная лицензия на него в карточке записи не указана. До публикации чего-либо производного от него источник нужно уточнить.

Мультидоменные папки `sociopolitical/` и `biomedical/` пока не используются: они про современный специальный язык, а не про архаизмы. Они пригодятся для оценки согласия разметчиков.

## Корпус «Повестей Белкина»

```bash
python -m archword.corpus --out data/corpus/belkin.json
```

Скрипт скачивает текст с lib.ru и делит его на повести. Если структура страницы изменилась и деление не удалось, он назовёт, какие заголовки не найдены.
