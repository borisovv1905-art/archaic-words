# Разметка собственного набора

Цель: понять, как модели, обученные на библейских и современных текстах, работают на прозе Пушкина. Для этого нужен небольшой размеченный набор из «Повестей Белкина».

## Как получить таблицу

```bash
python -m archword.corpus --out data/corpus/belkin.json
python -m archword.annotate --n 200 --out data/annotation/belkin_sheet.csv
```

Откройте CSV в Excel или Google Таблицах (кодировка UTF-8) и заполните колонку `label`.

## Шкала

Та же, что у публичных датасетов, чтобы можно было сравнивать напрямую:

| Оценка | Значение |
|---|---|
| 1 | слово знакомо, объяснять нечего |
| 2 | понятно по контексту |
| 3 | слышал, но уверенно не объясню |
| 4 | смутно догадываюсь |
| 5 | не знаю, нужен словарь |

Точную формулировку инструкции у авторов датасета нужно сверить по статье и при необходимости поправить таблицу выше.

## Правила

- Оценивайте **слово в этом предложении**, а не слово вообще.
- Ничего не гуглите во время разметки: мерится понятность без подсказок.
- Имена собственные пропускайте и ставьте в `note` значение `имя`. Таблица помечает имена эвристикой: заглавная буква не в начале предложения. Имя в начале предложения она не отличит, это известное ограничение.
- Размечайте за один-два подхода, пока не устали. Перед стартом запишите дату и то, что вы читали «Повести Белкина» до разметки, потому что это влияет на знакомство со словами.

## Почему слова выбираются случайно по группам частоты

Если размечать только «подозрительные» слова, модель не увидит обычных слов, а оценка качества получится завышенной. Таблица берёт слова случайно внутри пяти групп по современной частоте.

## Ограничения, которые нужно указать в отчёте

- Разметчик один, поэтому метрики измеряют согласие модели с вами, а не с «читателем вообще».
- Чтобы оценить шум разметки, через неделю повторно оцените 30–40 случайных слов и посчитайте согласие с самим собой: `archword.metrics.agreement`.
- Если слова размечены с помощью LLM, это нужно указать в README отдельной строкой.
- Если «слово» оказалось именем или ошибкой в тексте корпуса (в тексте lib.ru встречается «всь» вместо «все» из-за старой орфографии), оценку не ставьте, а в колонке note напишите `имя` или `ошибка`: такие строки в оценку не входят.
- Колонка `ipm` в Excel и Google Таблицах может превратиться в даты (число вроде 1,23 читается как «январь 1923»). В расчётах она не используется: частота берётся из словаря по самому слову, а в сохранённых CSV значения пересчитаны.
