# Карточка модели: archword

Короткий документ о том, что делает модель из демонстрации, на чём она обучена, насколько ей можно верить и где она ошибается. Числа получены кросс-валидацией и воспроизводятся командами из README.

## Что делает модель

По русскому слову (в тексте, без учёта контекста) оценивает, как бы его оценил читатель, чья разметка использована в обучении, по шкале 1-5 («1 - знаю, 5 - совсем незнакомо»). Из оценки получается вероятность того, что слово нужно пояснить (оценка не ниже 2). Демонстрация подсвечивает слова, у которых вероятность не ниже порога (по умолчанию 0,21).

Предназначена для: черновой подсветки слов, которые стоит проверить, при чтении русской классики XIX века; учебного проекта.
Не предназначена для: оценки сложности текста для школьников или иных групп читателей, автоматического решения, что пояснять в издании, и вообще любых решений, где ошибки модели имеют цену. Модель не объясняет значение слов.

## Устройство

- Линейная модель (Ridge, параметр регуляризации подбирается внутренней кросс-валидацией, 4 значения).
- Признаки слова: log10 частоты формы, log10 частоты леммы (колонка лемм словаря OpenCorpora), log10 частоты леммы по pymorphy3 (лемма от лемматизатора, частота - сумма частот всех форм), длина слова, tf-idf символьных n-грамм (2-4, с границами слова).
- Частоты берутся из частотного словаря русского языка 1992-2019 (`rus_freq_dictionary_1992-2019.csv`). Значения ниже 0,02 на миллион в таблицах не хранятся и считаются как «слова нет в словаре».
- Выход модели в шкале 0-1 переводится в оценку 1-5 и в вероятность логистической кривой, подобранной на предсказаниях вне обучения.
- Модель хранится в `models/model.json` (коэффициенты) и считается на numpy: без pickle и без scikit-learn во время работы. Совпадение с исходной scikit-learn-моделью проверяется при обучении и в тестах.

В демонстрации работает только эта линейная модель. Нейросеть (rubert-tiny2) и ансамбль из исследования в демонстрацию не входят: они требуют torch.

## Данные обучения

- 694 слова из «Повестей Белкина» Пушкина, размеченные одним читателем (автором проекта) в три раунда по шкале 1-5. Раунд 1: 200 слов случайно по группам частоты; раунд 2: 298 редких слов; раунд 3: 196 новых редких слов (и 40 повторных для оценки согласия с самим собой).
- Распределение оценок: 1 - 568 слов, 2 - 46, 3 - 39, 4 - 15, 5 - 26. Трудных (оценка не ниже 2) - 126 (18%), очень трудных (не ниже 3) - 80.
- Публичные данные про Библию (3364 слова, Zenodo 7419194) использованы только в исследовании нейросети, в линейную модель из демонстрации не входят.

## Качество

Пятикратная кросс-валидация по словам (слово целиком в одной части, трудные слова поровну по частям), предсказания вне обучения, 95% бутстрэп-интервалы:

| Показатель | Значение |
|---|---|
| Spearman с оценкой читателя | 0,444 [0,385; 0,499] |
| AUC, найти слова с оценкой не ниже 2 | 0,829 [0,790; 0,864] |
| AUC, найти слова с оценкой не ниже 3 | 0,827 [0,782; 0,865] |
| Порог 0,21: полнота / точность на разметке | 0,71 / 0,46 |

Для сравнения (те же слова, те же части): частота формы без обучения - Spearman 0,31; частота леммы по pymorphy3 без обучения - 0,395; нейросеть rubert-tiny2 после предобучения на Библии - 0,385; ансамбль нейросети и линейной модели - 0,47. То есть простая частота леммы уже даёт большую часть качества, линейная модель немного выше, а нейросеть сама по себе её не превосходит. Подробности и парные сравнения - в README.

Что значит порог 0,21: при нём модель находит около 71% слов, которые читателю были незнакомы, но среди подсвеченных слов реально незнакомыми оказывались только 46%. Почти каждое второе выделение лишнее. Порог выбран по лучшей F1 на предсказаниях вне обучения; для меньшего числа ложных срабатываний его нужно поднимать (в демонстрации есть ползунок).

## Известные ограничения и ошибки

- **Один читатель.** Модель предсказывает, что было незнакомо одному человеку, который хорошо знает русскую классику (80-90% слов он оценил единицей). Для другого читателя набор «трудных» слов будет другим. Согласие читателя с самим собой на повторной разметке умеренное (взвешенная каппа около 0,55), оценки со временем сдвигаются вниз, то есть шум в самой разметке сравним с различиями между моделями.
- **Один произведение, один период.** Обучение только на «Повестях Белкина». Перенос на других авторов (например, на Лермонтова) качественно проверялся на нескольких предложениях, количественно не измерялся.
- **Слепая зона: частые по словарю, но устаревшие слова.** Модель опирается на частоту и форму слова. Слова вроде «урядник» и «десятник» (частота около 0,9 на миллион, обычные буквы) она считает знакомыми, хотя читателю они могут быть не знакомы. Таких слов в обучающей выборке почти нет. Редкие слова, не отличающиеся по виду, и частые слова с устаревшим значением (например, «рассуждать» в старом смысле) модель не различает.
- **Нет контекста.** Слово оценивается само по себе, лемма берётся как самый вероятный разбор pymorphy3, омонимы могут путаться.
- **Имена.** Слова с заглавной буквы не в начале предложения по умолчанию не оцениваются. Это упрощение: настоящие имена отсекаются, но ошибочно могут отсекаться и обычные слова.
- **Мало трудных слов.** 126 положительных примеров, поэтому интервалы широкие и разность между близкими моделями (например, 0,42 и 0,44) статистически не различима.
- **Предсказания на словах из обучения оптимистичны.** Любые слова «Повестей Белкина» из разметки модель «видела» (проверка кросс-валидацией этого не учитывает при показе в демонстрации).
- **Нет внешнего теста.** Все метрики получены на тех же 694 словах (в кросс-валидации), без отдельной выборки другого автора.

## Как воспроизвести

```bash
pip install -e ".[dev,morph]"
python -m archword.train_final --raw data/raw --out-dir models    # обучение и экспорт, печатает метрики кросс-валидации
python -m pytest -q                                              # включая проверку готовой модели
streamlit run demo/app.py
```

Метрики моделей и сравнения лежат в `results/`.
